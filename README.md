# Trading Indicator
Designed and built a custom TradingView Pine Script v6 indicator for NQ/ES futures implementing a multi-timeframe ICT-style trading model, translating discretionary trading rules into structured, rule-based code across 7 timeframes.
Engineered logic to detect market structure, liquidity sweeps, order blocks, and fair value gaps, with a real-time dashboard and alert system, strengthening skills in algorithmic logic design and financial markets.
